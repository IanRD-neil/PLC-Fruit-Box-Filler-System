# Automatic Fruit Box Filling System

An industrial automation project developed using **Siemens TIA Portal V21** and an **S7-1215C PLC**.

## Project Overview

This project implements an automated fruit box filling system designed to fill each box with **10 pieces of fruit**.

The system uses conveyor belts, sensors, and sequential PLC control to detect and count the fruits and manage the filling process automatically. A **WinCC HMI** is also used for system monitoring and control.

## Technologies

* Siemens TIA Portal V21
* Siemens S7-1215C PLC
* WinCC HMI
* Industrial sensors
* Conveyor belts
* PLC sequential control

## Main Features

* Automatic fruit detection and counting
* Conveyor belt control
* Sequential filling process
* Automatic filling of 10 fruits per box
* HMI monitoring and control
* Safety and emergency-stop logic
